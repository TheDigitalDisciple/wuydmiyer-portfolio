# Wuydmiyer Fort-Monville — Portfolio Website

A responsive dark-navy portfolio starter inspired by the approved mockup. Built with plain HTML, CSS, and JavaScript so it is easy to edit and publish using GitHub Pages.

## Preview locally
1. Download and unzip this folder.
2. Open `index.html` in a modern browser.
3. For the best local development workflow, use VS Code and its Live Server extension.

## Files
- `index.html` — page content and sections
- `styles.css` — colors, layout, responsive behavior, cards, and motion
- `script.js` — mobile navigation, year, and scroll reveals
- `assets/Wuydmiyer_Fort-Monville_Resume.pdf` — résumé linked from the site

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `wuydmiyer-portfolio` (or another name you prefer).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root, not inside an extra nested folder.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish; the Pages screen will show the public URL.

## Before launch
- Confirm the résumé is the version you want public.
- Replace the CSS-generated sample project artwork with your own approved project images.
- Review every project description and remove anything you do not want public.
- Confirm email, phone, and LinkedIn links.
- The project tiles currently link to relevant sections; they are not yet individual case-study pages.
- Google Fonts load from the internet; the site still uses system font fallbacks if unavailable.

## Editing content
Open `index.html` in a code editor and search for the section heading or project title you want to change. Change visual styling in `styles.css`.
